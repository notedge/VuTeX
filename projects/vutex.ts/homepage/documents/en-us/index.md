# VuTeX Documentation

VuTeX brings document intent from different source languages into a shared semantic, layout and output pipeline. TeX is an optional input direction, not the core model.

## Start here

- [Install and get started](guide/install.md)
- [Product boundaries and rendering flow](guide/architecture.md)

## Products

- `@vutex/vutex`: TypeScript runtime facade and official CLI.
- `@vutex/wetex`: standalone formula WASM and JavaScript surface.
